# Smart Grabber

Программа с графическим интерфейсом для скачивания видео с YouTube в высоком качестве, вплоть до 4K. Написана на C++ с использованием Dear ImGui и DirectX 11.

## Как это работает
Для загрузки и обработки видео Smart Grabber использует:
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) для получения видео
- [FFmpeg](https://ffmpeg.org) для склейки видео и звука
- [Deno](https://github.com/denoland/deno) как вспомогательную среду для yt-dlp

Эти компоненты в программу **не входят** и скачиваются автоматически при первом запуске.

## Сборка
Нужны Windows и Visual Studio (C++, Desktop development).
1. Открой `4k.vcxproj`.
2. Выбери конфигурацию `x64` / `Release`.
3. Собери проект (Ctrl+Shift+B).
